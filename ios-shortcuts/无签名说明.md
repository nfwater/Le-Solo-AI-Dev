# 无签名快捷指令 — 怎么办？

iPhone 会拦截 **未签名的 `.shortcut` 文件**，提示：

> 不支持导入未签名的快捷指令文件

**这不是文件坏了，是 Apple 的安全策略。** 从 GitHub 下载的快捷指令都是未签名的，**无法在 iPhone 上直接「添加快捷指令」**。

---

## 方案一：Safari 网页版（最推荐）

不用导入任何东西。

### 1. 开启 GitHub Pages（只需一次）

Safari 打开：

**https://github.com/nfwater/Le-Solo-AI-Dev/settings/pages**

- **Build and deployment** → Source 选 **GitHub Actions**
- 保存

然后打开 Actions 页面，重新运行 **Deploy GitHub Pages**：

**https://github.com/nfwater/Le-Solo-AI-Dev/actions**

### 2. 使用

**https://nfwater.github.io/Le-Solo-AI-Dev/**

1. X App 复制链接  
2. 网页 → 粘贴链接 → 生成 PDF  
3. 保存或分享  

---

## 方案二：Scriptable 脚本（无需签名）

1. App Store 安装 **Scriptable**（免费）
2. 打开 `X-Tweet-To-PDF.scriptable.js`，**全选复制**  
   下载：https://raw.githubusercontent.com/nfwater/Le-Solo-AI-Dev/main/ios-shortcuts/X-Tweet-To-PDF.scriptable.js
3. Scriptable → **+** 新建脚本 → 粘贴 → 保存为「X转PDF」
4. 在 X 复制链接 → 运行脚本 → Safari 打开后：**分享 → 打印 → 存为 PDF**

---

## 方案三：有 Mac 时再导入快捷指令

```bash
shortcuts sign --mode anyone --input X-Tweet-To-PDF.shortcut --output 已签名.shortcut
```

把 **已签名.shortcut** 传到 iPhone 即可导入。

---

## 总结

| 方式 | 需要签名？ | iPhone 能用？ |
|------|-----------|--------------|
| GitHub 下载 .shortcut | 是 | ❌ 会被拦截 |
| Safari 网页版 | 否 | ✅ |
| Scriptable 脚本 | 否 | ✅ |
| Mac 签名后的 .shortcut | 已签名 | ✅ |

**不要再尝试导入未签名的 `.shortcut` 文件，一定会失败。**
