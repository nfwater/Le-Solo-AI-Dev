# iPhone 下载安装（3 步）

## 方法一：直接下载（最简单）

1. 用 **iPhone 的 Safari** 打开这个链接：

   **https://raw.githubusercontent.com/nfwater/Le-Solo-AI-Dev/main/ios-shortcuts/X-Tweet-To-PDF.shortcut**

2. 页面会提示下载，点 **允许** / **下载**
3. 下载完成后点文件，或在 Safari 地址栏左侧点 **下载图标** → 点 `X-Tweet-To-PDF.shortcut`
4. 自动跳转到「快捷指令」→ 点 **添加快捷指令**

---

## 方法二：从 GitHub 网页下载

1. Safari 打开：**https://github.com/nfwater/Le-Solo-AI-Dev/tree/main/ios-shortcuts**
2. 点文件 **`X-Tweet-To-PDF.shortcut`**
3. 点右上角 **⋯**（三个点）→ **Download**（下载）
4. 下载完成后在 Safari 的下载列表里点开该文件
5. 点 **添加快捷指令**

---

## 安装后怎么用

1. 在 X App 复制推文分享链接
2. 打开「快捷指令」App → 运行 **X推文转PDF**
3. 在分享面板保存或发送 PDF
